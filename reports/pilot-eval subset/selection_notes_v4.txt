chunking: W1.4 chunks the FULL ~1,089-doc corpus, and this allowlist is applied
later to score the pilot. (In v3 the subset was mis-framed as the chunking input.)

    forced set grew from 16 (v3) to 25 unique docs.

 5. THEME FRAMING — themes are the coarse curated-theme (ADR-0011 ID letter),
    to be re-tagged at W1.7; explicitly NOT the W1.7 taxonomy (which does not
    exist yet).

================================================================================
THEME FRAMING (audit fix #5)
================================================================================
"theme" = the 2nd character of the Article Code = the COARSE CURATED-THEME a
curator stamped at ingestion (ADR-0011: {Type}{Theme}{Number}; the theme letter
is an explicit, mutable hand-label, not content-derived). It is NOT the W1.7
taxonomy, which DOES NOT EXIST YET (W1.7 will design centroid topics and the
docs will be RE-TAGGED then). Theme-stratified selection here is on the coarse
curated label only and should be revisited once W1.7 lands.

================================================================================
BIOGRAPHY (audit fix #6)
================================================================================
All 35 biography codes are GC### — an ID-CONVENTION ARTIFACT: the biography
format (letter G) is conflated with theme C ("Biographical & Personal") at
curation, so biography appears only under theme C. This is NOT a topic-
distribution finding. The empty Biography A/B/D/E cells are therefore expected
structural blanks, not gaps.

================================================================================
SELECTION PROCEDURE (deterministic, reproducible)
================================================================================
1. Place all 25 forced docs into their (theme, format) cells.
2. Fill remaining cell slots by ASCENDING Article-Code from that theme+format
   pool, skipping any already selected. No doc twice; source corpus untouched.
3. Output order: theme (A-E), format (Column, Biography, Book, Speech), code asc.
Generator: scripts/build_pilot_subset_v4.py (deterministic; re-run = identical).
